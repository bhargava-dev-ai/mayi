# Security

mayi has had no outside security review yet. Do not use it alone to protect tools that move money.

## Reporting a vulnerability

Please do not open a public issue for a security hole. Use GitHub's private reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. Include the catalog, the call and what ran that should not have.

I will reply as soon as I can and credit you if you want that.

## What counts

A call that runs when the catalog says it should be held or rejected; an approval that works twice, for the wrong value or for the wrong session; a way to read or change application-controlled values; a way past the gateway's key checks.

Known limits are listed in the README and are not vulnerabilities by themselves, but a clear way to exploit one is welcome.
